# Search instructions by brand and model

## FACT

- Початковий стан: користувач відкрив QAuto та входить через `Guest log in`.
- Після входу в лівому меню доступний пункт `Instructions`.
- Тестові дані: Brand `BMW`, Model `X5`.
- Очікування: після пошуку відображається щонайменше одна картка інструкції; назва кожної показаної картки містить `BMW X5`; кожна картка має посилання або кнопку `Download`.
- Перевіряється пошук і відображення результатів, а не завантаження PDF.

## ASSUMPTION

- Сценарій є одним UI-тестом у Chromium.
- Стартова сторінка відкривається через `baseURL` з `playwright.config.ts`.
- Гостьовий вхід використовується як підготовка, а не як основна перевірка.
- Перед написанням тесту назви ролей, accessible names і структура картки будуть підтверджені в поточному UI через Playwright CLI.
- Тест перевіряє видимий результат пошуку, а не внутрішні API-виклики.

## Основний сценарій

1. Відкрити стартову сторінку QAuto.
2. Натиснути `Guest log in`.
3. Перейти до розділу `Instructions` через видимий пункт меню.
4. У полі `Brand` вибрати `BMW`.
5. Переконатися, що поле `Model` доступне після вибору бренду, і вибрати `X5`.
6. Натиснути `Search`.
7. Дочекатися завершення оновлення результатів без fixed wait.
8. Перевірити, що відображається щонайменше одна картка інструкції.
9. Перевірити, що назва кожної видимої картки містить `BMW X5`.
10. Перевірити, що кожна видима картка містить доступне посилання або кнопку `Download`.

## Критерії успіху

- Пошук виконується після вибору `BMW` і `X5`.
- Результати не є порожніми.
- Усі перевірені картки відповідають парі `BMW X5`.
- Для кожної перевіреної картки доступний `Download`.

## Критерії невдачі

- Не вдається відкрити `Instructions` після гостьового входу.
- `Model` недоступний або не містить `X5` після вибору `BMW`.
- Після натискання `Search` немає жодної картки.
- Показана картка не містить `BMW X5` у назві.
- У картці відсутнє посилання або кнопка `Download`.

## Межі та залежності

- Не додавати перевірку завантаження PDF.
- Не додавати registration, credentials, API-виклики або інші сценарії.
- Не використовувати CSS/XPath, fixed waits або непідтверджені accessible names.
- Model залежить від Brand, тому вибір `BMW` має передувати вибору `X5`.

## RISK

- Точні HTML-атрибути, ролі, accessible names і структура карток не задані вимогою.
- Дані та порядок результатів можуть залежати від поточного стану UI.
- Перевірка `BMW X5` потребує узгодження з фактичним текстом назви картки.

## CLI inspection gate

Після окремого підтвердження `APPROVE CLI INSPECTION` запустити CLI першою командою:

```text
npx playwright cli open https://qauto.forstudy.space --config=.playwright/cli.config.json
```

Під час інспекції підтвердити локатори для `Guest log in`, `Instructions`, `Brand`, `Model`, `Search`, картки, назви та `Download`. Якщо UI не підтверджує вимогу або для `BMW X5` немає результатів, повернути `STOP` і зафіксувати blocker замість вигадування очікування.
